# Panel rezerwacji

Narzędzie w przeglądarce dla gabinetu: wgrywasz eksporty rezerwacji (możesz kilka
miesięcy naraz), a otrzymujesz:

- **Do zadzwonienia** — pacjenci, którzy mieli już wizyty, a nie są zapisani na
  bieżący ani przyszły tydzień (z filtrami: przyszła wizyta, terapeuta, usługa,
  liczba wizyt, zakres dat, szukanie po nazwisku).
- **Trendy miesięczne** — liczba wizyt i przychód miesiąc do miesiąca, wzrost/spadek
  oraz ile brakuje, żeby rosnąć.

Przełącznik „Pomiń bezpłatne konsultacje" (domyślnie wyłączony) pozwala wykluczyć
pozycje typu „Bezpłatna rozmowa" / „Bezpłatny dobór specjalisty".

## Prywatność
Wszystko liczone jest **lokalnie w przeglądarce** — pliki z danymi pacjentów nie są
nigdzie wysyłane. Hostowana jest wyłącznie sama strona (`index.html`).

## Uruchomienie
Otwórz `index.html` w przeglądarce (dwuklik) albo udostępnij przez GitHub Pages.
